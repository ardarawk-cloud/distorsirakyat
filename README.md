# DISTORSI RAKYAT

Media independen punk, satir, dan kritik sosial Indonesia.

**Website:** https://distorsirakyat.nadmo.id/  
**GitHub:** https://github.com/ardarawk-cloud/distorsirakyat  
**Cloudflare Pages project:** `distorsirakyat` (akun NADMO)  
**Production branch:** `main`

## Deployment

✅ Project Cloudflare Pages yang sudah ada sekarang terhubung langsung dengan repository ini melalui integrasi GitHub.

Setiap perubahan ke branch `main` akan memicu deployment otomatis di Cloudflare Pages. **Tidak memerlukan upload ZIP, API token GitHub Secrets, project atau domain baru.**

Cek status deploy pada project Pages `distorsirakyat` di Cloudflare. Status push ke GitHub saja tidak cukup untuk menyatakan website telah diperbarui.

## Prinsip editorial

- Bukan anti-pemerintah; mengkritik korupsi, penyalahgunaan kekuasaan, dan kebijakan yang merugikan warga.
- Fakta diverifikasi dari sumber dengan tanggal dan konteks. Satir, opini, dan dugaan dipisahkan.
- Hak jawab, koreksi, dan data pribadi dihormati.
- Form "Suara Warga" saat ini hanya membuat draf teks di perangkat pengguna, **belum mengirim laporan online**.

## Teknologi

HTML, CSS, JavaScript statis. File produksi ada di `index.html`, `assets/`, dan berkas root seperti `_headers` dan `404.html`. Tidak perlu build command untuk static site ini.
